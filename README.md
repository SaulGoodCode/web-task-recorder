# Web Task Recorder

> 一个基于 Chrome MV3 扩展的网页操作"录制-回放"工具：录制你在网页上的操作，按计划自动回放执行。可用于每日签到、定时打卡、表单自动提交等场景。

## 特性

- **录制-回放模式**：借鉴 Playwright 的 record-replay 机制，无需写死业务逻辑
- **通用任务调度**：每条任务可独立设置执行时间，支持每日循环
- **步骤可视化编辑**：录制后可在弹窗里调整每步的等待时间、输入值、任务名称和时间
- **无步骤任务兜底**：不录制任何步骤时，默认行为是打开网址、加载完成 3 秒后关闭——加载成功即视为成功
- **健壮回放**：元素查找多重回退（role+name 优先，CSS/text 兜底）+ 强制点击（pointerdown/mousedown 完整事件链）+ 遮挡检测
- **输入合并防抖**：连续输入同一输入框时合并为一条 fill 步骤，避免步骤爆炸
- **状态反馈**：任务卡片实时显示待执行/成功/失败/执行中，及上次执行时间

```
└──────────┘              └────────────┘                └────┬─────┘
      ↑                        ↑   ↑                         │ 录制操作
      │ 保存完成通知            │   │ 步骤回放                  ↓
      │                        │   │                   ┌──────────┐

│ (tasks)    │                    │

                            │ player.js  │
                            └────────────┘
```

## 文件说明

| 文件 | 职责 |
|------|------|
| [manifest.json](manifest.json) | MV3 配置，使用 `scripting` 权限动态注入 |
| [selector.js](selector.js) | Playwright 风格选择器工具（role+name 优先，CSS/文本回退） |

## 使用流程

1. 点击扩展图标，在弹窗输入**网址**、**执行时间**、（可选）任务名称
2. 点"开始录制"→ 打开目标页面，右上角出现录制浮窗
3. 在页面正常操作（点按钮、填表单、按回车）
4. 操作完成后点浮窗"保存"→ 自动生成任务并回到弹窗
5. 到点自动执行，也可在弹窗点"执行"手动触发测试

> 不录制任何步骤直接保存，则视为"仅访问网址"任务：加载成功即成功。

## 编辑任务

点击任务卡片上的"编辑"按钮，可：
- 修改任务名称、执行时间
- 调整每步的**等待(ms)**（执行完该步后等多久进入下一步）
- 修改 fill/select 步骤的输入值、wait 步骤的等待时长
- 新增"等待步骤"、删除已有步骤

## 安装

1. 下载本项目
2. Chrome 打开 `chrome://extensions/`
3. 开启"开发者模式"
4. 点"加载已解压的扩展程序"，选择本项目目录
5. 扩展图标出现在工具栏

## 定时回放排查

- 手动与定时执行共用队列，同一任务在排队或执行时不会重复启动。
- 每个操作最多等待目标元素 60 秒，页面 DOM 更新时立即重新查找；每次回放有 3 分钟超时保护。
- 定时任务失败后，关闭本次标签页并从头重新执行，最多重试 2 次（共 3 次）。成功后关闭标签页并停止重试；第 3 次仍失败则保留最后的标签页。无步骤任务也适用。
- 手动执行（包括“执行全部”）只执行一次，不重试；失败保留标签页，成功关闭标签页。
- 控制台日志包含执行次数，以及找不到元素时的具体选择器、当前网址和页面可见状态，便于排查。
- 更新代码后，在 `chrome://extensions/` 重新加载扩展。现有录制任务无需重新创建。
- 验证定时时，请保留浏览器运行，选择至少 6 分钟后的时间（调度会随机前后偏移 5 分钟）。
- 本地回归检查：`node --test tests/playback.test.cjs`。模拟测试不代表真实 Telegram 签到已验证成功。
